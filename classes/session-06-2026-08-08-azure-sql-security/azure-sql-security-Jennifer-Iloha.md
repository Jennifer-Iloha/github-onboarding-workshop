## Key Concepts I Learned

<!-- Write the main ideas covered in today's session -->

* Transparent Data Encryption (TDE) encrypts data at rest automatically
* SQL authentication vs. Microsoft Entra ID authentication for Azure SQL
* Firewall rules and network restrictions control who can even reach the database in the first place
* Always Encrypted protects sensitive data so it stays encrypted even during query processing, with only the application (not the database engine) able to decrypt it
* Dynamic Data Masking limits what non-privileged users actually see, without touching the underlying data
* Azure SQL Auditing tracks database events for compliance and monitoring
* Microsoft Defender for SQL detects anomalous activities and potential threats like SQL injection attempts

## My Takeaways

<!-- What was most valuable to you personally from this session? -->
